# Open-conversation, grounded-facts Infobot prompt v23

- Source basis: live production rejection of an ordinary conversational turn
  after generic evidence pages were injected into an empty retrieval result
- Release date: `2026-08-21`
- Behavior release: `infobot-open-conversation-grounded-facts`
- Code-owned policy ID: `2026-08-21-v23`
- Parent policy: `2026-08-18-v22`

This version separates open conversation from factual site grounding without
adding a greeting classifier or a canned reply. When retrieval finds approved
site evidence, the model selects one record and every factual claim remains
grounded in it. When retrieval finds no evidence, the candidate list remains
empty and the model uses `ASK` to respond naturally without inventing Fortune
facts. Generic homepage and navigation records are no longer injected merely
to force an ordinary turn through the factual validator.

The model-authored conversational path keeps only the bounded privacy,
instruction-disclosure, URL, and response-length checks. It does not enforce a
sentence grammar, punctuation pattern, or canned clarification menu. Factual
grounding and current-status checks still apply when the model selects an
approved source.

The exact v22 compiled artifact is preserved in
`2026-08-18-v22-compiled.md`. See `../current.md` for the v23 compiled prompt.
