# Digital Equity model-first prompt v25

- Source basis: approved pages across the public Digital Equity site and its live calendar
- Release date: `2026-08-28`
- Behavior release: `digital-equity-model-first`
- Code-owned policy ID: `2026-08-28-v25`

This version makes the model and its selected source record the response path.
It removes the lexical grounding classifier, the 40-word rejection gate, and
silent answer clipping that caused valid provider responses to become 502s.

The remaining checks are deliberately small: the provider must return the JSON
contract, `pick` must be an approved supplied record or `ASK`, and the response
must not ask for personal details. Factual instructions remain in the system
prompt: use only supplied Digital Equity evidence, do not guess, preserve stated
limits, and use the live calendar record and current date for schedule questions.

The exact v24 compiled artifact is preserved in
`2026-08-26-v24-compiled.md`. See `../current.md` for the v25 compiled prompt.
