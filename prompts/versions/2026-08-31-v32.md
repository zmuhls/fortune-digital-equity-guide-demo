## Change from v31

The guide now chooses the freshest, most specific current record and answers a
supported part before asking for more information. Clarification is reserved
for cases where one missing detail would materially change the answer and the
available evidence cannot support a useful partial response.

Ordinary answers are one or two short sentences, under 40 words, and
end after the answer. Follow-ups add supported information or name the exact
source limit once instead of repeating, restarting, or offering a menu. The
compiled contract is 587 words, down from 678 words in v31.

The pre-model privacy boundary is implemented separately in code. In this
release it requires an actual disclosed private value, preserves the preceding
safe conversation, and does not create a synthetic guide turn. Model output is
not run through a second personal-information classifier. Pages, Wix, and the
server retain the latest eight complete exchanges for the next model turn.
